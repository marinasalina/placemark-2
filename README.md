# PlaceMark

PlaceMark is a web application that allows users to create, manage, and explore personal points of interest (placemarks).

Users can sign up, log in, add places they want to remember, upload images, organise locations into categories, and view their data in different visual formats such as maps, reports, and charts.

## Features

- User registration and login
- Secure password hashing with bcrypt
- JWT-based authentication
- Add, edit, and delete placemarks
- Upload images for placemarks using Cloudinary
- Categorise placemarks
- Rate places as recommended or not recommended
- Interactive map view using Leaflet
- Weather information for saved locations using OpenWeather API
- Data visualisation with charts using ECharts
- Reports view for stored placemarks
- Future trends / projections page

## Technologies Used

This project was built using:

- SvelteKit
- TypeScript
- MongoDB
- Mongoose
- JWT authentication
- bcrypt
- Leaflet
- OpenWeather API
- Cloudinary
- ECharts
- Bulma CSS
- Firebase (authentication setup support)
